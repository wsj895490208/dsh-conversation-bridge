# v0.2.0 — model-inclusive experimental release

The local embedding model now ships inside the tgz. End users do not download
model files, configure a model directory or access Hugging Face. First use
copies the bundled files into a private cache and checks every SHA-256 locally.
Missing or corrupt bundled files fail explicitly rather than silently fetching.

## Model and licensing

- Uses the original publisher's `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` ONNX export, explicitly Apache-2.0, revision `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`.
- Includes five files totaling 127,536,798 bytes before compression. The ONNX file is renamed for the local loader; file bytes are unchanged.
- Publisher model card, Apache-2.0 text, exact sources and hashes ship under `notices/model/`.
- The model is included in the Release installer, not Git or the source zip. Project code remains MIT; model assets retain Apache-2.0.

## Upgrade

Model fingerprints prevent old and new vectors from mixing. Existing raw
histories, corrections and tombstones remain; legacy vectors rebuild
automatically in the background. Full-text retrieval remains available meanwhile.
No paid history reconstruction is triggered by this vector migration.

## Install

Fully quit Harness, then run from the directory containing the downloaded tgz:

```powershell
dsh plugin --profile desktop add .\dsh-conversation-bridge-0.2.0.tgz --ignore-scripts
```

Restart Harness and choose **导入网页对话**. The package includes the embedding
model. The package manager may still need its registry for JavaScript/runtime
dependencies; chat and summaries still use your configured model provider.
“Offline” refers to model preparation and local indexing, not fully offline chat.

## Validation and compatibility

- Windows / Harness 0.2.1-rc.3 / V4; other versions remain blocked.
- Synthetic tests cover missing/corrupt files, no-network copy/cache repair,
  cancellation/retry, fingerprint isolation and upgrade scheduling.
- The actual extracted release package is tested with an empty cache and disabled
  preparation networking, then performs 384-dimensional local indexing and a
  synthetic Chinese recall probe.
- Native compaction/persistence/mode/image checks remain synthetic and do not
  call a paid model. Final desktop confirmation/open still needs manual acceptance.

Download the tgz for installation. The source zip is for development and excludes
weights; `SHA256SUMS.txt` covers both archives. Version 0.1.0 remains available as
a historical release and is not replaced.
