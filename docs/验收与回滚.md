# 验收与回滚

首版验证范围：Windows、DeepSeek Harness 0.2.1-rc.3、会话格式V4、Node 24。其他宿主版本不自动放行导入。

`Build.ps1` 运行单元测试、原生压缩与磁盘回读、原生模型协议与模式切换、向量先加载后的原生图片保存验收，再打包并扫描发布内容。测试使用合成对话与模拟模型服务，无真实模型调用、私人历史重建或图片上传。

机器可读记录见 `native-validation.json`、`interaction-validation.json`、`image-validation.json` 及 `release.json`。真实对话的连续性、长历史重建和主观体验由使用者在确认页主动验收。

## 构建与安装

运行 `tools/Build.ps1 -HarnessRoot <DSH安装目录>`，将生成的tgz通过官方CLI安装。`tools/Install.ps1` 要求 Harness 已正常退出；可传入 `ReplacePackage` 和 `PreviousProject`，先建立一致性备份，再通过官方CLI替换指定插件。替换后数据默认独立，旧会话只保留历史，不迁入旧人格、索引或测试问答。

修改数据目录使用原生插件配置编辑器。若卸载的插件仍是新任务默认预设，先在原生预设管理中恢复标准模式；不会更改已有会话的预设。

## 回滚

正常退出 DSH，通过官方 `dsh plugin --profile desktop remove dsh-conversation-bridge` 卸载新版，再安装替换备份中记录的旧包。需要恢复原插件配置时使用备份里的原生配置文档，通过官方配置编辑器恢复；不直接覆盖活动存储。

本插件和旧项目的原始数据均保留。备份中的SQLite使用备份API生成；原生日志只在宿主退出后复制。凭据不进入备份。回滚不删除新插件数据，需要重新启用时可再次安装同版本。
