# v0.1.0 — experimental release

DeepSeek official web JSON → select branch → local preview → native rolling
context reconstruction → isolated local index → resumable Harness session.

## Included

- Parent-chain import with roles, timestamps, source mapping and attachment metadata.
- Native threshold-based rolling compaction; below threshold, no summary call.
- Durable checkpoints and successful-summary reuse; unclear outcomes pause for explicit retry.
- Local full-text and multilingual MiniLM vector indexing; on-demand `memory_search`.
- Conversation / engineering tool selection, native persistence and no-backup removal.
- Source, locked dependencies, third-party notices and synthetic validation records.

## Compatibility and limits

- Validated: Windows, Harness 0.2.1-rc.3, V4 sessions, Node 24. Other host versions are blocked pending validation.
- Native integration checks use synthetic data and mocked model responses. Desktop file selection/upload/branch scanning were verified; final confirmation/open still require manual acceptance.
- The factory summary template is preserved and currently favors English engineering checkpoints.
- This does not reproduce the web service's undisclosed context or guarantee emotional/personality continuity. The README documents the original, unsuccessful continuity goal.
- No real paid-history reconstruction was run for release validation.
- Model weights and dependency binaries are not included. The converted model has no separate explicit license metadata; see the third-party qualification before mirroring weights.
- No npm release, web login-token import or online attachment fetching.

## Install

Fully quit Harness, then run from the directory containing the downloaded tgz:

```powershell
dsh plugin --profile desktop add .\dsh-conversation-bridge-0.1.0.tgz --ignore-scripts
```

Restart Harness and select **导入网页对话**. Model files download locally on first
preparation. Compaction and chat use the model provider configured by the user.

The source zip is an explicit public-file archive; `SHA256SUMS.txt` covers both
downloadable archives. Native host files, private histories, caches and backups
are excluded. See the repository README for data/removal semantics and rollback.
